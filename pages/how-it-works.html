Safety model

Guardrails on the guardrail.

An autonomous system touching production has to be more careful than a human, not less. This is what keeps it honest.

Shields are reversible

A shield only catches the exact fingerprint (exception type + function) it was armed for. Operators can lift or re-arm it at any time.

Humans approve deploys

The pipeline stops at "verified". Nothing reaches the running service until a person clicks approve.

Tests run in a sandbox

Patched modules are written to a disposable temp directory and tested with a separate pytest process with a timeout.

No silent behavior change

Shadow replay requires the patch to return byte-identical output for real traffic that already worked. Any diff counts as a regression.

Escalates when unsure

If no patch survives three rounds, or the engine errors, the incident escalates and the shield stays up.

Everything is auditable

Every event is streamed and kept. The PR carries the timeline, rounds, tests and replay evidence for review.
